# Image Rotator

A clean React + Vite image rotator.

## Features

- Upload JPG, JPEG, PNG, WEBP and other browser-supported image formats
- Drag and drop upload
- Rotate 90° left/right
- Custom rotation angle
- Horizontal and vertical flip
- Reset edits
- Download the transformed image
- Responsive UI
- Image processing happens locally in the browser

## Run

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```
