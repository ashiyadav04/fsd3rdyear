# React Image Rotator

A complete Vite + React image slider.

## Features

- Images stored locally in `src/assets`
- `useState` controls the current `index`
- `setIndex` increments/decrements the image
- Previous/Next buttons
- Dot navigation
- `setInterval` automatically changes the image every 2 seconds
- `clearInterval` cleanup on unmount

## Run

```bash
npm install
npm run dev
```
